# Purpose
I saw u/RrOoSsSsOo's on r/asahilinux in which I decided to make a script based on it. \
it has 3 scripts:
1. install.sh: installs steam and sets up a Steam.desktop file so that you can run it without opening the terminal and entering the muvm command everytime you want to play.
2. proton-ge.sh: installs the latest proton-ge version and sets it up in steam.
3. cleanup.sh: removes everything, this is if the installation of steam is bricked and you don't want to manually remove things.

 # Issues
 cannot move the window with the touchpad/mouse unless, you hold the meta key. or just use keyboard shortcuts

 # platform tested on.
 - M1 air with 8GB RAM
 - Asahi fedora (Plasma)
